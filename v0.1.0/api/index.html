PlotPhyloTree — Module
PlotPhyloTree

Publication-quality phylogenetic tree figures in pure Julia, drawn as SVG (PNG/PDF with the Librsvg extension). Rectangular, circular and fan layouts, clade highlights and labels, support symbols, ancestral-state pies, node age bars, time scales with geological colours, heatmap and bar rings, and images.

using PlotPhyloTree
tree = randtree(40)
p = treeplot(tree; layout=:circular)
highlight!(p, tipnames(tree)[1:8]; label="Clade A")
savefig("tree.svg", p)

Figure

PlotPhyloTree.treeplot — Function
treeplot(tree; kwargs...) -> TreePlot

Start a tree figure. tree is a PhyloTree, a Newick string, or a path to a Newick/Nexus file.

Layout

  • layout = :rectangular — or :circular, :fan (an open circle), or :dendrogram (rectangular, growing downwards).
  • branchstyle = :square — elbows; :round (rounded corners), :curved (smooth sweeps) or :slanted (straight lines from parent to child).
  • cladogram = false — ignore branch lengths and align the tips.
  • ladderize = false — sort clades by size (true, or :left/:right).
  • direction = :right — rectangular only: :right, :left, :down, :up.
  • openangle — circular/fan: gap in degrees (default 6 for :circular, 180 for :fan). rotation = 0 — rotate the whole circle clockwise (degrees).
  • inner = 0 — circular: radius (px) of an empty hole at the centre.
  • rootedge = 0 — length in px of a stem drawn below the root.
  • radius, width, tipspacing — size of the tree itself in px (the circle's radius to the furthest tip, or the depth and per-tip spacing of a rectangular tree). All are chosen from the number of tips by default.

Branches

  • color — a colour; a vector/dictionary/function of per-node values; or a Symbol naming a node annotation (e.g. :rate). Numbers are coloured with colormap over colorrange and get a colour bar; categories get palette colours and a legend.
  • linewidth — a number or per-node values; linestyle = :solid.

Text and theme

  • tiplabels = true, italic = false, align = false, fontsize (auto).
  • font = "Helvetica Neue, Helvetica, Arial, sans-serif".
  • theme = :light — or :dark, :minimal (transparent background).
  • background — overrides the theme's background colour.
  • title, subtitle, legend = :auto (:right, :bottom, :topright, :topleft, :bottomright, :bottomleft, :none), legendtitle, margin = 16.

PlotPhyloTree.nodevalues — Function
nodevalues(p, v) -> Vector{Any}

Expand v to one value per node (nothing where missing). v may be a dictionary keyed by node references (labels, indices or collections of tip labels meaning their MRCA), a vector over all nodes, a vector over tips in drawing order, a Symbol naming a node annotation, a function of the node index, or a single value for every node.

PlotPhyloTree.highlight! — Function
highlight!(p, clade; color=auto, alpha=0.2, label=nothing, from=:stem, to=:labels,
           stroke=nothing, linewidth=1, branches=false, kwargs...)
highlight!(p, clades::AbstractDict; palette=:default, kwargs...)

Shade the region behind clade (a node, tip label or collection of tip labels whose MRCA is used), as a wedge in circular layouts and a rounded box in rectangular ones.

  • color — the colour, drawn at opacity alpha; by default the next colour of the palette.
  • label — also add a cladelabel! in the same colour (extra keywords such as level, fontsize and along go to it).
  • from — where the shading starts: :stem (half-way along the branch above the clade), :node, :root, or a distance in px before the node.
  • to — where it ends: :labels (past the tip labels and its own clade label, or every label if it has none), :tips, :all (past every ring), or a distance in px beyond the furthest tip.
  • branches = true also colours the clade's branches and tip labels.

The dictionary form highlights several clades, label => clade.

PlotPhyloTree.cladelabel! — Function
cladelabel!(p, clade, text; color=:fg, textcolor=nothing, level=1, fontsize=auto,

Label a clade with a bar spanning its tips and a name beyond the tips (and beyond the tip labels). Labels with the same level share a ring; higher levels sit further out, as for nested taxonomic ranks. In circular layouts the name follows the arc (along = true); set along = false for radial text.

PlotPhyloTree.support! — Function
support!(p; key=:support, breaks=auto, colors=green→red, marker=:circle, size=5,
         labels=auto, title="Support", hidebelow=nothing, kwargs...)

Mark internal nodes by support value (bootstrap, posterior, …) read from the node annotation key (or given as per-node values). Values are binned by breaks (default [70, 90, 95], or [0.7, 0.9, 0.95] for values in 0–1) and each bin gets a colour from colors (highest first) and a legend entry. Nodes below hidebelow are not marked.

PlotPhyloTree.nodelabels! — Function
nodelabels!(p; text=:support, nodes=:internal, fontsize=auto, color=:muted,
            position=:branch, digits=2, bold=false, halo=true)

Write text at nodes: an annotation key (default the support values), node labels (text = :label), or per-node values. position = :branch puts it above the branch just before the node (the usual place for support values); :node puts it just after the node. A label that would overlap something else moves to the other place (or below the branch); text too long for its branch always goes after the node. With hideoverlaps = true, labels that fit nowhere are left out instead of drawn over other things.

PlotPhyloTree.timescale! — Function
timescale!(p; ticks=auto, title="", rings=true, bands=true, labels=true, axis=true,
           geo=nothing, geoalpha=0.35, origin=0, color=nothing, bandcolor=nothing,
           fontsize=auto, to=:tips)

A time axis for a dated (ultrametric) tree, measured back from the tips, which are at age origin. Circular layouts get concentric rings and an axis along the opening; rectangular ones get vertical grid lines and an axis below the tree. bands = true shades every other interval.

geo = :epochs, :periods or :eras colours the background by the geological time scale (ICS colours; ages in Ma), or pass a vector of (name, abbreviation, from, to, colour) tuples. to = :labels or :all carries the rings past the tip labels.

PlotPhyloTree.tipheatmap! — Function
tipheatmap!(p, data; columns=nothing, colormap=:viridis, colorrange=nothing,
            palette=:default, cellwidth=12, gap=1.5, colnames=true, title="",
            border=:background, offset=6)

A ring (circular) or block (rectangular) of coloured cells beside the tips. data can be

  • a dictionary tip => value (one column) or tip => vector (several columns),
  • a matrix with one row per tip, with rows = tip labels (default: the tips in drawing order),
  • a vector of per-tip values, or
  • a NamedTuple of any of the one-column forms, giving named columns that are coloured independently (e.g. a numeric trait and a category).

Numbers are coloured by colormap, anything else by palette; each adds a legend titled title (or the column name).

PlotPhyloTree.savefig — Function
savefig(path, p; scale, kwargs...) -> path

Write p to path, choosing the format from the extension:

  • .svg, or .html (an HTML page holding the SVG);
  • .png, .pdf — need using Librsvg_jll (an optional extension); scale = 2 multiplies the pixel size of PNG output;
  • .tex — a standalone LaTeX document drawing the figure with TikZ, and .tikz — just the tikzpicture, to \input (see tikzstring);
  • .typ — a standalone Typst document drawing it with CeTZ (see cetzstring); pass standalone = false for a file to #include.

For TikZ and CeTZ, scale = 1 multiplies every length and other keywords go to tikzstring/cetzstring. Their images are written next to path.

PlotPhyloTree.tikzstring — Function
tikzstring(p; standalone=false, scale=1, font=nothing) -> String

The figure as TikZ code: a tikzpicture environment to \input into a LaTeX document (needs \usepackage{tikz}), or with standalone = true a complete document that compiles on its own (pdflatex, lualatex).

One px of the layout becomes one bp (1/72 in), and scale multiplies every length, including font sizes and line widths — use it to fit a column (\resizebox works too). Labels are set in the document's font at the layout's sizes: font is LaTeX font code added to every label (e.g. "\\sffamily"); by default the figure's font option picks \sffamily, \rmfamily or \ttfamily.

Images are written beside the file by savefig ("tree.tex" → tree-img-1.png …); SVG images are converted to PDF, which needs the Librsvg extension.

source
PlotPhyloTree.cetzstring — Function
cetzstring(p; standalone=false, scale=1, cetz="0.4.2", font=nothing) -> String

The figure as Typst code drawing it with CeTZ. The code imports @preview/cetz:<cetz> and draws a cetz.canvas; #include the saved file in a Typst document, or with standalone = true it sets the page to fit the figure so it compiles on its own (typst compile tree.typ).

One px of the layout becomes one pt; scale multiplies every length, including font sizes and line widths. font is a Typst font name or list (default: the figure's font option, falling back to Typst's default). Pick cetz to match your Typst version (CeTZ 0.3.0 needs Typst ≥ 0.11, 0.4 needs 0.13.1, 0.5 needs 0.14).

Images are written beside the file by savefig ("tree.typ" → tree-img-1.png …); Typst draws SVG images itself.

Makie

PlotPhyloTree.phyloplot — Function
phyloplot(tree_or_plot; kwargs...)
phyloplot!(ax, tree_or_plot; kwargs...)

Draw a tree figure with Makie (needs using CairoMakie, GLMakie, … — the Makie extension). The argument is a TreePlot built with treeplot and its layers, or a tree (a PhyloTree, Newick string or file), which is drawn with treeplot's defaults.

The figure is laid out exactly as for SVG and translated into Makie plots (poly, lines, text, image), so it composes with other plots: one data unit is one px of the layout, with y pointing up and the tree's root region near the origin of the layout. Use phylofigure for a ready-made Figure sized to the tree.

Attributes:

  • linewidthscale = 1 — Makie line widths are in screen px, not data units; scale them when the axis is drawn larger or smaller than the layout.
  • fontscale = 1 — multiplies label sizes (text is sized in data units).
  • images = true — draw tipimages! images (decoded with FileIO; SVG images are skipped).
